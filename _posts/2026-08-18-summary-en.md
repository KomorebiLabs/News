## [Mojo Programming Language Released as Open Source Under Apache 2 License](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) ⭐️ 8.0/10

Mojo has been released as open source under an Apache 2 license, following its 1.0 launch last week. This fulfills a promise Modular made back in May 2023 to open-source the compiler and toolchain. This is significant for the Python and AI ecosystems, as Mojo was designed to combine Python-like syntax with systems-level performance, particularly for GPU programming. The open-source release removes adoption barriers and invites community contributions to a language targeting high-performance computing. Mojo originally aimed to be a full superset of Python, but around August 2025 the roadmap shifted: the language now positions itself as its own entity optimized for GPU programming with Python-inspired syntax, rather than guaranteeing 100% compatibility with existing Python code.

rss · Simon Willison · Aug 18, 21:39

**Background**: Mojo is a programming language developed by Modular, designed to offer the productivity of Python with the performance of systems languages like C and Rust. It features static typing and a borrow checker inspired by Rust, while using syntax reminiscent of Python. The language is particularly targeted at AI and GPU computing workloads where Python's runtime speed is a bottleneck. The Apache 2 license is a permissive open-source license that allows commercial use, modification, and distribution.
