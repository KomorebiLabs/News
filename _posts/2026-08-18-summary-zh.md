## [Mojo 编程语言以 Apache 2 许可证开源发布](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) ⭐️ 8.0/10

Mojo 编程语言在上周发布 1.0 版本后，现已以 Apache 2 许可证开源发布。这兑现了 Modular 在 2023 年 5 月做出的开源编译器和工具链的承诺。 这对 Python 和 AI 生态系统具有重要意义，因为 Mojo 旨在结合类 Python 语法与系统级性能，尤其适用于 GPU 编程。开源发布消除了采用障碍，并邀请社区为面向高性能计算的语言做出贡献。 Mojo 最初的目标是成为 Python 的完整超集，但在 2025 年 8 月左右路线图发生了转变：该语言现在定位为一种独立语言，采用类 Python 语法优化 GPU 编程，而非保证与现有 Python 代码 100% 兼容。

rss · Simon Willison · 8月18日 21:39

**背景**: Mojo 是由 Modular 开发的编程语言，旨在提供 Python 的生产力以及 C 和 Rust 等系统级语言的性能。它具有受 Rust 启发的静态类型和借用检查器，同时使用类 Python 的语法。该语言主要针对 AI 和 GPU 计算工作负载，在这些场景中 Python 的运行速度是瓶颈。Apache 2 许可证是一种宽松的开源许可证，允许商业使用、修改和分发。
